Advanced Clinical Settings

The response window is set automatically by Challenge Level. Stimulus speed changes the interval between inhibition trials, not the response window. Planning puzzles come from fixed seeds: the same set and level always gives the same five puzzles.

1. Rule Switch

Sort by colour, shape or size. Maintain a rule and adapt when the sorting rule changes. Supports tapping and dragging.

2. Inhibition Challenge

Progress from Go/No-Go to selective inhibition and conflict inhibition. Commission and omission errors are measured separately.

3. Planning Challenge

Plan ahead to solve route, tower and key-and-door puzzles. Five puzzles per session, scaling from simple routes to hidden-map planning.
